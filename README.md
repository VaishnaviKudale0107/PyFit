# 🏋️ PyFit

PyFit is a Python-based fitness and health tracking application with a modern **CustomTkinter GUI**.  
It helps users log exercises, track progress, and visualize fitness data with charts.

---

## ✨ Features
- 📝 Log workouts and exercises
- 📊 Visualize progress with **matplotlib**
- 🖼️ Beautiful **CustomTkinter** interface
- 🔧 Import/Export workout data
- 📂 Includes example `exercise.json`
- 🖼️ Icons and screenshots included in `media/`
